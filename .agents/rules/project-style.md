# Quy Chuẩn Thiết Kế Dự Án "Răng Đen Môi Đỏ"

- **Phong cách chủ đạo:** Tạp chí Nghệ thuật (Editorial Art Zine), thông tin cô đọng, giàu tính thị giác.
- **Bảng màu cố định:**
  - Nền gạch bông xanh lục bảo trầm: `#071619`, `#0b2227`, `#143c44`, `#1e5763`
  - Điểm nhấn hồng cánh sen / môi đỏ: `#d83b7c`, `#f25a99`
  - Chữ bạc khảm & vàng đồng: `#efedf6`, `#c8c4dc`, `#d8b568`
- **Cấu trúc 2 giao diện:**
  - Giao diện Web (`.web-magazine-view`) và Giao diện Điện thoại (`.mobile-showcase-wrapper`) trong [index.html](../../index.html).
  - Cổng server local mặc định: `5588` (tránh cổng `8080`).
